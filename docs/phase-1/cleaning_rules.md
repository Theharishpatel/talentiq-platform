# Cleaning Rules

## Signals

github_activity_score
- -1 -> None

offer_acceptance_rate
- -1 -> None

## Strings

Apply:
- strip()
- collapse multiple spaces

Fields:
- headline
- summary
- company
- title
- skill name
- location

## Skills

Normalize casing.

Example:
- python -> Python
- aws -> AWS
- sql -> SQL

## Titles

AnalyticsEngineer
-> Analytics Engineer

## Duplicates

Remove duplicate skills inside candidate profile.
